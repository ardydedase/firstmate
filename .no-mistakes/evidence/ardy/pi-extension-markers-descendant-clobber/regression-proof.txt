All suites run with node v22.23.2 (the pi-bundled node, which imports the
`.ts` extensions natively; the ambient nvm node v18 on this host cannot).

## Known environmental failures inside this harness session (identical on the unmodified base)

- `tests/fm-omp-harness.test.sh` test 1 ("a leaked FM_OMP_HARNESS without an omp
  ancestor must not relabel a claude worker, got 'pi'"): fails because these
  runs execute inside a pi harness session, so the ancestry walk genuinely
  detects a pi ancestor. Verified identical on base commit 259a669; the suite
  passes fully once that one invocation is skipped, which is how the new omp
  marker tests above were reached.
- `tests/fm-pi-watch-extension.test.sh` and `tests/fm-turnend-guard.test.sh`
  first fail under the ambient node v18 in PATH (ERR_UNKNOWN_FILE_EXTENSION for
  `.ts`); with node v22.23.2 they pass fully. `tests/fm-pi-branch-extension.test.sh`
  reports the same node-version issue ("skip: installed
  @earendil-works/pi-coding-agent package not found") under node 18.
